Ghazely

It rots the page while you stare. A real rest heals it. Settings are saved as you change them.

Rest and snooze

How long you must go with no typing, mouse or touch input and no playing media before the page heals. Ghazely cannot count a rest shorter than 15 seconds.
How many times a day you can snooze the lock screen. Each snooze brings the next haunt back sooner and stronger. The count resets at local midnight. Set 0 to turn snoozing off.
How many minutes one snooze holds the haunt off before it comes back.
